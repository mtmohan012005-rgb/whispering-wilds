# Supported Platforms & Architectures

## Supported Operating Systems
- **Windows**: Windows 10 (64-bit), Windows 11 (64-bit)
- **macOS**: macOS 12 Monterey, macOS 13 Ventura, macOS 14 Sonoma, macOS 15 Sequoia
- **Linux**: Ubuntu 22.04 LTS+, Debian 12+, Arch Linux, Fedora 38+, SteamOS 3.0+

## Supported CPU Architectures
- **x86_64 / x64**: Intel Core / AMD Ryzen processors
- **ARM64**: Apple Silicon (M1/M2/M3/M4) and officially tested Linux ARM64 systems

> [!NOTE]
> Supported configurations are strictly those listed in our verified test matrix. We do not claim universal support for untested configurations.
