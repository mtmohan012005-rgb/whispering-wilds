# Storefront System Requirements

## Windows
- **Minimum**:
  - OS: Windows 10 (64-bit, Version 1909 or higher)
  - Processor: Intel Core i3-7100 / AMD Ryzen 3 1200
  - Memory: 4 GB RAM
  - Graphics: Intel HD Graphics 620 / AMD Radeon Vega 6
  - DirectX: Version 11
  - Storage: 3 GB available space
- **Recommended**:
  - OS: Windows 10 / Windows 11 (64-bit)
  - Processor: Intel Core i5-10400 / AMD Ryzen 5 3600
  - Memory: 8 GB - 16 GB RAM
  - Graphics: NVIDIA GeForce GTX 1660 / AMD Radeon RX 5600 XT
  - DirectX: Version 11 / 12
  - Storage: 4 GB available SSD space

## macOS
- **Minimum**:
  - OS: macOS 12 Monterey
  - Processor: Apple M1 / Intel Core i5 (9th Gen)
  - Memory: 8 GB RAM
  - Graphics: Apple 7-Core GPU / AMD Radeon Pro 5300M
  - Storage: 3 GB available space
- **Recommended**:
  - OS: macOS 14 Sonoma or higher
  - Processor: Apple M2 / Apple M3
  - Memory: 16 GB RAM
  - Graphics: Apple 10-Core GPU or higher
  - Storage: 4 GB available space

## Linux
- **Minimum**:
  - OS: Ubuntu 22.04 LTS / Debian 12 / SteamOS 3.0+
  - Processor: Intel Core i3-7100 / AMD Ryzen 3 1200
  - Memory: 4 GB RAM
  - Graphics: Intel UHD Graphics / AMD Radeon (Mesa 22+)
  - Storage: 3 GB available space
- **Recommended**:
  - OS: Ubuntu 24.04 LTS / Arch Linux / Fedora 39
  - Processor: AMD Ryzen 5 3600 / Intel Core i5-10400
  - Memory: 16 GB RAM
  - Graphics: AMD Radeon RX 6600 / NVIDIA RTX 3060
  - Storage: 4 GB available space
