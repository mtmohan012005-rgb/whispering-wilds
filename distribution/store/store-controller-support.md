# Controller & Input Support Disclosure

- **Controller Support Level**: Full Controller Support
- **Supported Controller Models**:
  - Microsoft Xbox Wireless Controller / Xbox Series X\|S / Xbox Elite Controller
  - Sony PlayStation DualSense (PS5) / DualShock 4 (PS4)
  - Standard XInput / DirectInput Compatible PC Gamepads
- **Features**:
  - Hotplugging: Connect or disconnect at any time during gameplay without needing a restart.
  - Dynamic button prompts matching connected controller hardware.
  - Fully remappable controls via in-game settings.
  - Concurrent Keyboard & Mouse support.
