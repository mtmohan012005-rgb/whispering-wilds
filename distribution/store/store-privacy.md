# Storefront Privacy & Security Disclosure

- **User Accounts & Identity**:
  - The game operates completely independently of external storefront accounts for core gameplay.
  - Zero store credentials, passwords, or payment tokens are ever requested, processed, or saved by the application.
- **Data Collection**:
  - The game collects zero tracking, analytics, or behavioral telemetry.
  - User progress is saved locally in standard OS application data folders and optionally synced through storefront cloud storage.
- **GDPR & Privacy Compliance**:
  - Fully compliant with GDPR data minimization principles.
  - Uninstalling the application preserves local game saves unless the user explicitly chooses to purge their user data folder.
